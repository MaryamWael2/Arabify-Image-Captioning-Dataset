# Arabify: Arabic Image Captioning Dataset

**Arabify** is a high-quality, open-source dataset for image captioning in Modern Standard Arabic. It is designed to help researchers and developers build and evaluate machine learning models for vision-to-language tasks, specifically targeting Arabic captions.

---

## 📦 Dataset Overview

- **Total Images**: 3502
- **Captions per Image**: 2
- **Language**: Modern Standard Arabic
- **Format**: CSV + image folder

---

## 📁 Structure

```

Arabify-Image-Captioning-Dataset/
├── images/
│   ├── image1.jpg
│   └── ...
├── FINAL_two_captions_df.csv
└── README.md

````

- `images/`: Images used in the dataset
- `FINAL_two_captions_df.csv`: Two captions per image
